# Кибер Арена — симулятор киберспортивных турниров (Unity, телефон)

## Как запустить
1. Unity Hub → New project → шаблон **2D** (или Universal 2D). Подойдёт Unity 2021.3 LTS, 2022.3 LTS или Unity 6.
2. Скопируй папку `Assets/EsportsSim` в папку `Assets` проекта.
3. Открой любую сцену (хоть пустую `SampleScene`) и нажми **Play**.
   Игра создаётся сама из кода, на сцену ничего добавлять не нужно.
4. В окне Game выбери вертикальное разрешение, например 1080x2400.

## Сборка на телефон
- **Android:** File → Build Settings → Android → Switch Platform → Build.
- **iOS:** то же самое, только платформа iOS, дальше сборка через Xcode.
- Ориентация экрана: Player Settings → Resolution and Presentation → Default Orientation = **Portrait**.
  Код тоже включает портретный режим при старте.

## Игроки и команды
- У игрока есть ник, страна (флаг), скилл (информация) и сила. Флаг показывается в левом верхнем углу фото и рядом с ником в бою. У команды — название, бонус к силе и логотип.
- **Итоговая сила = сила игрока (50–75) + бонус команды (+1…+10).**
- **Числа силы и бонусов в игре не показываются** — ни при выборе, ни в бою, ни в таблицах.
  Их видно и можно менять только в **Главное меню → Настройки**: вкладки по регионам (сила игроков, кнопки −/+)
  и вкладка «Команды» (бонусы). Изменения сохраняются на устройстве; «Сбросить всё к исходным» возвращает значения из JSON.
- **Свободный бой:** нажми на игрока, затем выбери ему команду. Так же для второго игрока. Матч до 2 побед.

## Экран боя
- Сзади фон арены.
- Игрок 1: фото в левом верхнем углу, справа от него зелёная полоса HP, флаг и ник, команда с логотипом, регион, скилл, действия хода.
- Игрок 2: фото в правом нижнем углу, слева от него то же самое зеркально.
- В центре чат с результатами ходов. Один ход в секунду (скорость x1/x2/x4, можно пропустить).

## Механика боя
- Каждую секунду оба игрока одновременно бросают три шанса: атака, отход (уклон) и защита (блок).
- **Атака** бьёт на `8 + сила × 0,12` (от 14 до 17), с разбросом ±30%. 10% ударов критические (×1,7).
- **Отход** — полный уклон от удара в этом тике.
- **Защита** — блок, проходит только 40% урона.
- У каждого 100 HP. Равные игроки выдерживают в среднем 6–7 полных ударов.

Шансы действий от силы:

| Действие | Сила 50 | Сила 75 |
|---|---|---|
| Атака | 50% | 62% |
| Отход | 14% | 20% |
| Защита | 30% | 38% |

Вероятность победы в матче Bo3 (симуляция 20 000 матчей):

| Матчап | Победа сильного |
|---|---|
| 62 против 62 | 50% |
| 65 против 60 | 65% |
| 70 против 60 | 77% |
| 75 против 50 | 97% |
| 70+10 против 70+2 (один игрок в разных командах) | 70% |
| 75+10 против 50+2 | 99% |

## Формат сезона
Меню сезона — это 5 регионов, Wild Card и чемпионат мира.

1. **Регионы в любом порядке.** Выбираешь регион и играешь его до конца.
   Сыгранный регион становится серым, в карточке остаются чемпион (логотип, фото и ник игрока) и логотипы 2-го и 3-го мест.
   - **Драфт.** Команды по очереди (в порядке списка) выбирают по одному игроку из 20 игроков региона.
     Ты можешь выбирать за каждую команду сам или нажать «Автовыбор» / «Автодрафт до конца».
     Игрок закреплён за командой до конца сезона.
   - **Лига.** Каждый с каждым. Места: победы → разница карт → личные встречи.
   - **Плей-офф.** 1-е и 2-е места сразу в полуфинал. Плей-ин: 3–6 и 4–5.
     Полуфиналы: 1-е место против самого низкого посева из прошедших. Финал и матч за 3-е место.
   - **Путёвки на ЧМ:** чемпион, финалист и победитель матча за 3-е место.
2. **Wild Card** (открывается после всех 5 регионов). Все команды без путёвки (36) в случайном порядке.
   «Царь горы»: первые две играют, проигравший вылетает, победитель встречает следующую команду.
   Последний матч — финал. Победитель становится 16-й командой ЧМ.
3. **Чемпионат мира.** Автоматическая жеребьёвка: в каждой из 4 групп — победитель лиги, 2-е место, 3-е место
   и одна из «остальных» (лишние 1-е, 2-е, 3-е места и победитель Wild Card). Состав групп не меняется.
   Группы — каждый с каждым дважды, выходят двое. Четвертьфиналы A1–B2, B1–A2, C1–D2, D1–C2, полуфиналы, финал.
   Чемпионом мира объявляются команда и её игрок, они попадают в «Зал славы».

Все матчи — до 2 побед. Прогресс сохраняется после каждого матча.
