# Кибер Арена — симулятор киберспортивных турниров (Unity, телефон)

## Как запустить
1. Unity Hub → New project → шаблон **2D** (или Universal 2D). Подойдёт Unity 2021.3 LTS, 2022.3 LTS или Unity 6.
2. Скопируй папку `Assets/EsportsSim` в папку `Assets` проекта.
3. Открой любую сцену (хоть пустую `SampleScene`) и нажми **Play**.
   Игра создаётся сама из кода, на сцену ничего добавлять не нужно.
4. В окне Game выбери вертикальное разрешение, например 1080x2400.

## Сборка на телефон
- **Android:** File → Build Settings → Android → Switch Platform → Build.
- **iOS:** то же самое, только платформа iOS, дальше сборка через Xcode.
- Ориентация экрана: Player Settings → Resolution and Presentation → Default Orientation = **Portrait**.
  Код тоже включает портретный режим при старте.

## Игроки и команды
- У игрока есть ник, страна (флаг), скилл (информация) и сила. Флаг показывается в левом верхнем углу фото и рядом с ником в бою. У команды — название, бонус к силе и логотип.
- **Итоговая сила = сила игрока (50–75) + бонус команды (+1…+10).**
- **Числа силы и бонусов в игре не показываются** — ни при выборе, ни в бою, ни в таблицах.
  Их видно и можно менять только в **Главное меню → Настройки**: вкладки по регионам (сила игроков, кнопки −/+)
  и вкладка «Команды» (бонусы). Изменения сохраняются на устройстве; «Сбросить всё к исходным» возвращает значения из JSON.
- **Свободный бой:** нажми на игрока, затем выбери ему команду. Так же для второго игрока. Матч до 2 побед.

## Экран боя
- Сзади фон арены.
- Игрок 1: фото в левом верхнем углу, справа от него зелёная полоса HP, флаг и ник, команда с логотипом, регион, скилл, действия хода.
- Игрок 2: фото в правом нижнем углу, слева от него то же самое зеркально.
- В центре чат с результатами ходов. Один ход в секунду (скорость x1/x2/x4, можно пропустить).

## Механика боя
- Каждую секунду оба игрока одновременно бросают три шанса: атака, отход (уклон) и защита (блок).
- **Атака** бьёт на `8 + сила × 0,12` (от 14 до 17), с разбросом ±30%. 10% ударов критические (×1,7).
- **Отход** — полный уклон от удара в этом тике.
- **Защита** — блок, проходит только 40% урона.
- У каждого 100 HP. Равные игроки выдерживают в среднем 6–7 полных ударов.

Шансы действий от силы:

| Действие | Сила 50 | Сила 75 |
|---|---|---|
| Атака | 50% | 62% |
| Отход | 14% | 20% |
| Защита | 30% | 38% |

Вероятность победы в матче Bo3 (симуляция 20 000 матчей):

| Матчап | Победа сильного |
|---|---|
| 62 против 62 | 50% |
| 65 против 60 | 65% |
| 70 против 60 | 77% |
| 75 против 50 | 97% |
| 70+10 против 70+2 (один игрок в разных командах) | 70% |
| 75+10 против 50+2 | 99% |

## Формат сезона
Меню сезона — это 5 регионов, Wild Card и чемпионат мира.

1. **Регионы в любом порядке.** Выбираешь регион и играешь его до конца.
   Сыгранный регион становится серым, в карточке остаются чемпион (логотип, фото и ник игрока) и логотипы 2-го и 3-го мест.
   - **Драфт.** Команды по очереди (в порядке списка) подписывают по одному игроку — **из любого региона**.
     Подписанный игрок закреплён за командой до конца сезона, другая команда взять его уже не может
     (в том числе команды регионов, которые драфтятся позже). Свой регион в списке показан первым.
     Ты можешь выбирать за каждую команду сам или нажать «Автовыбор» / «Автодрафт до конца».
   - **Лига.** Каждый с каждым. Места: победы → разница карт → личные встречи.
   - **Плей-офф.** 1-е и 2-е места сразу в полуфинал. Плей-ин: 3–6 и 4–5.
     Полуфиналы: 1-е место против самого низкого посева из прошедших. Финал и матч за 3-е место.
   - **Путёвки на ЧМ:** чемпион, финалист и победитель матча за 3-е место.
   - **Выбывание:** две последние команды каждой лиги покидают сезон и не играют в Wild Card.
2. **Wild Card** (открывается после всех 5 регионов). Участвуют все команды без путёвки, кроме двух последних команд каждой лиги.
   - **Первый этап:** случайные пары, один матч, проигравший вылетает — остаётся половина (18).
     При нечётном числе одна команда проходит без игры — она всегда открывает «царя горы» первым матчем.
   - **Царь горы:** оставшиеся в случайном порядке; победитель матча остаётся, проигравший вылетает, его место занимает следующая.
     Последний матч — финал. Победитель становится 16-й командой ЧМ.
3. **Чемпионат мира.** Автоматический посев по регионам:
   - в каждой из 4 групп первое место занимает чемпион одной из лиг **LCK, LCS, LEC, LPL**;
   - остальные 12 команд (чемпион Континентальной Лиги, все 2-е и 3-и места, победитель Wild Card) случайно
     распределяются так, чтобы две команды одного региона не оказались в одной группе.
   Групповой этап в **два круга**: внутри группы каждый играет с каждым дважды, выходят двое.
   Четвертьфиналы A1–B2, B1–A2, C1–D2, D1–C2, полуфиналы, финал. Чемпионом мира объявляются команда и её игрок, они попадают в «Зал славы».

## ESL One (веб-версия)
Разовый турнир **без команд**: выбираются только игроки, сила = сила игрока, в сетке — никнеймы.
- **4 игрока — Double Elimination:** верхняя сетка (2 матча, финал ВС), нижняя сетка (проигравшие 1-го раунда, финал НС с проигравшим финала ВС), гранд-финал.
- **8 игроков — Single Elimination:** 1/4 финала, полуфиналы, финал.
- **16 игроков:** 4 группы по 4 (два круга), выходят двое, четвертьфиналы A1–B2, B1–A2, C1–D2, D1–C2, полуфиналы, финал.
- **24 игрока — формат Pro League:** 4 группы по 6 (каждый с каждым), 4–6 места вылетают.
  Первые места — плей-ин (A1–C1, B1–D1). 2-е и 3-и — раунд 1 (A2–B3, B2–A3, C2–D3, D2–C3), раунд 2, раунд 3 против проигравших плей-ина,
  полуфиналы против победителей плей-ина, финал.

## ESL Pro League (веб-версия)
Играют **команды с игроками**, как в сезоне. Сначала приглашаешь 24 команды из 51, затем идёт **драфт**:
команды по очереди (в порядке приглашения) получают игрока, которого выбираешь ты — из любого региона
(регион команды показан первым). Последний выбор можно отменить. Формат — как ESL One на 24.
Победитель — **чемпион мира по версии ESL**.

## Зал славы
Отдельная вкладка в главном меню: **Чемпионы мира** (победители ЧМ в сезонах лиги), **Pro League** (чемпионы мира по версии ESL),
**ESL One**. У каждого — фото, ник, флаг и команда, в составе которой он выиграл.
Сезоны лиги идут циклами по 10: после 10-го сезона снова «Сезон 1», и зал чемпионов мира начинается заново.

> Новые правила Wild Card, посев ЧМ, ESL One, ESL Pro League и зал славы сделаны в веб-версии (`Web/`, `index.html`). Unity-версия работает по старым правилам.

Все матчи — до 2 побед. Прогресс сохраняется после каждого матча.
