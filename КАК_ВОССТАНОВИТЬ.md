# Кибер Арена — как всё восстановить

В этом архиве всё, из чего собрана игра: код, данные игроков и команд, картинки (исходные и готовые) и скрипты.

## Что где лежит
| Папка / файл | Что это |
|---|---|
| `Web/kiber-arena.html` | **Готовая веб-версия одним файлом.** Открывается в любом браузере, всё уже внутри. |
| `Web/app.js`, `Web/style.css` | Исходный код веб-версии. |
| `Web/build.py` | Собирает `kiber-arena.html` из кода и картинок Unity-проекта. |
| `Assets/EsportsSim/` | Unity-версия: код (`Scripts`) и ресурсы (`Resources`). |
| `Assets/EsportsSim/Resources/roster.json` | Все 100 игроков: ник, страна, сила, описание. |
| `Assets/EsportsSim/Resources/teams.json` | Все 51 команда: название, регион, бонус, логотип. |
| `Assets/EsportsSim/Resources/Portraits, Logos, Flags, Regions, Arena` | Готовые картинки для игры. |
| `Tools/source/uploads` | Оригиналы картинок, которые ты присылал (групповые фото и логотипы). |
| `Tools/source/players, logos, regions` | Вырезанные из оригиналов фото игроков и логотипы. |
| `Tools/*.py` | Скрипты подготовки картинок (см. ниже). |
| `README.md` | Описание механики, баланса и формата сезона. |
| `ЧТО_НУЖНО.md`, `ШАБЛОН_*.csv` | Как присылать новых игроков и команды. |

## Самый простой способ — веб-версия
1. Открой `Web/kiber-arena.html` в браузере: игра работает сразу.
2. Чтобы снова получить ссылку на claude.ai, пришли этот файл (или весь архив) в чат с Claude и попроси опубликовать как артефакт.
   Облачное сохранение хранится в самом артефакте на claude.ai: при новой публикации прогресс начнётся заново,
   если не перенести его (Claude может прочитать сохранение из старого артефакта и записать в новый).

## Пересобрать веб-версию после изменений
Нужен Python 3:
```
pip install pillow numpy scipy
cd Tools && python3 build_assets.py     # только если менял фото/логотипы в Tools/source
cd ../Web && python3 build.py            # собирает kiber-arena.html
```

## Скрипты картинок (Tools)
- `grid.py <картинка> <папка> <номер первого> <колонок>` — режет групповое фото на отдельных игроков (`pNNN.png`).
- `split.py` — то же для картинок без ровной сетки.
- `eyes.py` — показывает, где найдены глаза (для выравнивания голов).
- `build_assets.py` — выравнивает все портреты по глазам (подсказки `eyes` в roster.json), готовит логотипы.
- `make_flags.py` — рисует флаги стран.
